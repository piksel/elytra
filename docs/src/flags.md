
# Flags

| Bit        | Name                   | Decription   |
|------------|------------------------|--------------|
| `00000001` | ReadOnly  | Inidicating that writing to the field is not supported |
| `00000010` |  HasHelp ||
| `00000100` |  HasIcon ||
| `00001000` |  HasOptions | |
| `00010000` |  DynOpts  | Indicating that the options changes over time and can be refreshed |
| `00100000` |  DynValue | Flag indicating that the value changes over time and can be refreshed |
